# Сводка прогресса

Обновлено: 16 сентября 2026.

## Официальная программа

Всего в перечне «Синергии»: **230 уроков**.

На текущий момент в журнале есть явная связь с **6 уникальными официальными темами**:

- Русский язык: ID 1 — общие сведения о языке, неологизмы, историзмы, архаизмы;
- Литература: ID 18 — А. Н. Островский «Гроза»;
- Алгебра: ID 96–99 — функция, график функции, монотонность, чётность/нечётность.

Это не означает, что все шесть окончательно закрыты. Связь означает только, что тема уже изучалась и для неё есть запись состояния.

## Фундамент

В `knowledge/progress.yaml` отдельно записаны базовые темы, которые не надо смешивать со счётчиком 230 уроков: дроби, проценты, таблица умножения, устройство параболы, базовая геометрия, части речи, падежи и литературная аргументация.

## Как считать дальше

- `program` + уникальный `curriculum_id` — прогресс по официальной программе;
- `base` — восстановленный школьный фундамент;
- `deepening` — углубляющий материал;
- уровень 3 и выше означает, что навык уже выполнялся самостоятельно, но его всё равно нужно иногда проверять после паузы.

Для быстрого пересчёта: `python scripts/progress.py`.
