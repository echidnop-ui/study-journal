# Учебный журнал

Репозиторий хранит состояние обучения по ускоренной программе 10–11 класса, чтобы ChatGPT/Codex могли продолжать занятия без потери контекста.

## Ближайшие цели

- промежуточная аттестация за 10 класс — ориентир около 5 октября 2026, дата пока не подтверждена;
- итоговое сочинение — 2 декабря 2026;
- параллельно — восстановление школьного фундамента и подготовка к ЕГЭ.

## Как читать репозиторий

1. `CURRENT.md` — точная точка продолжения.
2. `RULES.md` — правила преподавания.
3. `curriculum/synergy-10.md` — полный перечень 230 уроков «Синергии» для 10 класса.
4. `knowledge/progress.yaml` — знания, пробелы и уровни освоения.
5. `sessions/` — журнал проведённых занятий.

## Шкала уровня

- `0` — не проверено;
- `1` — объяснено;
- `2` — выполняется с подсказкой;
- `3` — самостоятельно;
- `4` — воспроизводится после паузы;
- `5` — устойчиво.

## Тип записи

- `program` — тема официальной программы;
- `base` — необходимый фундамент;
- `deepening` — углубление сверх обязательной программы.

Исходные данные мигрированы из учебных файлов и Notion в сентябре 2026 года. Notion оставляется как архив, GitHub — как рабочее состояние.
