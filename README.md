# Учебный журнал

Репозиторий хранит состояние обучения по ускоренной программе 10–11 класса, чтобы ChatGPT/Codex могли продолжать занятия без потери контекста.

## Ближайшие цели

- промежуточная аттестация за 10 класс — ориентир около 5 октября 2026, дата пока не подтверждена;
- итоговое сочинение — 2 декабря 2026;
- параллельно — восстановление школьного фундамента и подготовка к ЕГЭ.

## Как читать репозиторий

1. `CURRENT.md` — точная точка продолжения.
2. `RULES.md` — правила преподавания.
3. `curriculum/synergy-10.md` — полный перечень 230 уроков «Синергии» для 10 класса.
4. `knowledge/progress.yaml` — актуальные знания, пробелы и уровни освоения.
5. `errors/errors.yaml` — актуальные ошибки и слабые места.
6. `reviews/queue.yaml` — рабочая очередь повторения.
7. `sessions/` — нормализованный журнал проведённых занятий.
8. `archive/notion-2026-09-16/` — полный исторический снимок служебных записей старого журнала Notion на момент миграции.

## Шкала уровня

- `0` — не проверено;
- `1` — объяснено;
- `2` — выполняется с подсказкой;
- `3` — самостоятельно;
- `4` — воспроизводится после паузы;
- `5` — устойчиво.

## Тип записи

- `program` — тема официальной программы;
- `base` — необходимый фундамент;
- `deepening` — углубление сверх обязательной программы.

## Рабочее состояние и архив

GitHub — основной журнал. Файлы `knowledge/`, `errors/`, `reviews/`, `sessions/` и `CURRENT.md` используются для продолжения обучения.

Notion не удалён и остаётся исходным архивом. Его исторические строки дополнительно сохранены в `archive/notion-2026-09-16/`, чтобы старые ошибки, повторения и формулировки не потерялись, но не засоряли актуальное состояние дубликатами.
