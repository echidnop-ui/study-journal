# Учебный журнал

Репозиторий хранит состояние обучения по ускоренной программе 10–11 класса, чтобы ChatGPT/Codex могли продолжать занятия без потери контекста.

## Ближайшие цели

- промежуточная аттестация за 10 класс — рабочая дата **26 октября 2026**;
- цель аттестации — проходной результат минимум на «3» / зачёт по каждому обязательному предмету;
- итоговое сочинение — 2 декабря 2026;
- параллельно — восстановление школьного фундамента и подготовка к ЕГЭ.

До 26 октября главный показатель прогресса — готовность пройти аттестацию по каждому предмету, а не процент глубоко изученных тем из 230.

## Как читать репозиторий

1. `ASSESSMENT.md` — стратегия подготовки к 26 октября.
2. `assessment/readiness.yaml` — текущий статус готовности по каждому предмету.
3. `CURRENT.md` — точная следующая задача.
4. `RULES.md` — правила преподавания.
5. `curriculum/synergy-10.md` — полный перечень 230 уроков «Синергии» для 10 класса.
6. `knowledge/progress.yaml` — актуальные знания, пробелы и уровни освоения.
7. `errors/errors.yaml` — актуальные ошибки и слабые места.
8. `reviews/queue.yaml` — рабочая очередь повторения.
9. `sessions/` — нормализованный журнал проведённых занятий.
10. `archive/notion-2026-09-16/` — исторический снимок старого журнала Notion.

## Статусы готовности к аттестации

- `not_diagnosed` — репрезентативный пробник ещё не решён;
- `below_pass` — результат ниже проходного;
- `pass_borderline` — проходной результат уже получен, но без устойчивого запаса;
- `pass_with_margin` — проходной результат подтверждён с запасом;
- `auto_or_not_required` — отдельная сдача, вероятно, не требуется; нужно подтверждение школы.

## Шкала знания отдельной темы

- `0` — не проверено;
- `1` — объяснено;
- `2` — выполняется с подсказкой;
- `3` — самостоятельно;
- `4` — воспроизводится после паузы;
- `5` — устойчиво.

## Тип записи знания

- `program` — тема официальной программы;
- `base` — необходимый фундамент;
- `deepening` — углубление сверх обязательной программы.

## Рабочее состояние и архив

GitHub — основной журнал. Notion не используется как рабочая система и остаётся только исходным архивом. Исторические записи дополнительно сохранены в `archive/notion-2026-09-16/`.
